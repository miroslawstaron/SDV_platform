Inside a software-defined vehicle

A CARLA city drive with control software you can inspect and replace

Measure. Understand. Improve.

This platform runs locally with Docker Desktop on Windows. CARLA 0.9.16 is the default simulator. Its native Windows server uses Vulkan on the RTX 4090. Docker hosts the SDV services and CARLA Python client. SUMO/Mapillary remain available for legacy recordings. The ECUs exchange real functional CAN and SOME/IP messages, and their decisions change the simulated drive. Source: compose.yaml and README.md.

The services behind the dashboards

17 active Docker services connect to a native CARLA server on this machine.

Sources: compose.yaml, scripts/Start-Carla.ps1, carla_service.py, docs/carla.md. The plant reaches the SDK through /data/carla-service.sock. The SDK reaches the native server on host.docker.internal, RPC port 2000 and streaming port 2001. The optional carla-docker profile replaces the native server on a compatible GPU host. Arrows show logical data connections, not physical bus wiring.

Native CARLA server on Windows

Physics and rendering

  • Official CARLA 0.9.16 Windows release.
  • Vulkan on the NVIDIA RTX 4090.
  • Hidden windowed surface, Epic quality and sound disabled.

How SDV connects

  • Docker’s SDK client reaches host.docker.internal.
  • RPC uses port 2000; camera streaming uses 2001.
  • The launcher starts the server; Stop-Sdv stops its owned process.

This server runs natively on Windows. The SDV services and Python client run in Docker.

Source: scripts/Start-Carla.ps1 and docs/carla.md. Installed at %LOCALAPPDATA%/SDV/CARLA/0.9.16. The first official archive download is approximately 7.3 GiB and resumes if interrupted. The launcher prepares signed legacy Microsoft dependency DLLs beside the executable. Launch flags include -windowed -nosound -quality-level=Epic -ResX=640 -ResY=360 -vulkan -preferNvidia. The 640x360 viewport is separate from the 1920x1080 camera sensors.

On this Windows Docker Desktop machine the stock image used software Vulkan; the active setup uses native Windows Vulkan. How the control units communicate

Navigation → controller
→ drive, brake and lane units
→ simulator → sensors

The controller decides what to do. The actuator units apply its requests; sensors report the result.

SOME/IP · network services
Navigation sends the desired speed, lane and distance left.
CAN FD · vehicle messages
Control requests, applied actions, obstacle distance and pedestrian alerts.
VSS · standard signal names
KUKSA stores reported values for other software to read.

Click a control unit or message in E/E architecture to see who sends it, who uses it and its current values.

Navigation also observes CAN through its adapter; its intent uses SOME/IP. A control command must traverse the controller and the actuator ECU before plant propulsion changes. Source: contracts/catalog.json, contracts/vehicle.dbc, web/src/ArchitectureView.tsx, backend/sdv/application.py.

How image similarity is measured

Compare the 64 bits in two visual fingerprints. Fewer differences mean a higher score:

Similarity = 100 × (1 − differing bits / 64)

Differing bitsSimilarityInterpretation
0100.0%Identical fingerprints
198.4%Counts as a similar view
887.5%Lowest score that counts as a match
1675.0%Does not count as a match

100% means the fingerprints match. “Same stored image” means both observations share one archived file.

Hamming distance is the bit count of the XOR of the two 64-bit pHashes. The dashboard reports the largest similarity among other captures, rounded to one decimal place. The exact score for d=1 is 98.4375%, displayed as 98.4%. A d=9 comparison scores 85.9375% (85.9%) and is below the match threshold. New zero-distance pHash matches reuse the first stored image even when incoming bytes differ. Same stored image compares archived image IDs, not incoming byte streams. This is a hash resemblance measure, not geographic distance or a confidence score. Source: backend/sdv/imagery.py (HASH_BITS, MAX_DISTANCE and similarity), web/src/imageSimilarity.ts and web/src/SimilarityDashboard.tsx.
